## 🤝 我们是谁

LessLive 是一个研究与实践阿德勒理论的开放组织，我们研究如何建立和经营高质量人际关系，构建滋养自己的生活圈。


## 🧭 我们怎么做

人人都是生活的研究员，探索个人生存与生活方式的最佳实践

- **读书会**：阿德勒思想的爱好者们共同学习和交流
- **训练营**：系统学习课题分离和共同体感受并实践
- **工作坊**：现实生活中各应用场景的真实实践计划
- **实验室**：持续探索和改良更多能帮助实践的方法
- **[工具箱](https://github.com/lesslive/LessLive)**：把你的生活变成人们愿意追下去的故事

## 📜 社区活动

这是一个开放的社会实验：**把朋友圈变成生活圈**。

这是 LessLive 官方发起的第一个行动计划。你可以成为自己的生活研究员，试着把你的生活变成人们愿意追更的故事，看看朋友圈能不能慢慢变成一个真正的生活圈。

## 🏡 入驻 LessLive，获得行动的勇气

将包含你实践成果的仓库，部署到 LessLive 组织，向来自各领域的 LessLive 成员乃至所有 GitHub 用户展示你的故事，和我们一起，交流经验、探讨问题、共同研究，这是属于你的生活圈。

- 让你的 AI 替你去串门：阅读大家的仓库，回来讲给你听
- [立即申请加入LessLive社区](https://github.com/orgs/lesslive/discussions/1)：同样的，让他们也认识你
