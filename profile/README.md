# LessLive

Maximize the world, yet minimize living

世界最大化，但生活最小化

---

## 🤝 我们是谁

LessLive 是一个研究与实践阿德勒理论的开放组织，我们研究人际关系的构建与维护，构建高质量生活圈。


## 🧭 我们怎么做

人人都是生活的研究员，探索个人生存与生活方式的最佳实践

- **读书会**：阿德勒思想的爱好者们共同学习和交流
- **训练营**：系统学习课题分离和共同体感受并实践
- **工作坊**：现实生活中各应用场景的真实实践计划
- **实验室**：持续探索和改良更多能提升效率的方法
- [工具箱](https://github.com/lesslive/LessLive)：把你的生活变成人们愿意追下去的故事。

## 📜 社区活动

这是一个开放的社会实验：**把朋友圈变成生活圈**。

这是 LessLive 官方发起的第一个行动计划，探索个人生存与生活环境最佳实践。你可以成为自己的生活研究员，把你正在推进的事公开出来，看看朋友圈能不能慢慢变成一个真正的生活圈。

## 🏡 入驻 LessLive，成为生活研究员

把你的仓库部署到 LessLive 组织，向所有成员公开你的行动计划和实践进度。在这里，你会得到鼓励，也去鼓励别人。

- [去看看其他研究员们的仓库](https://github.com/lesslive)：进入他们的仓库认识他们
- [立即申请加入LessLive社区](https://github.com/orgs/lesslive/discussions/1)：同样的，让他们也认识你
