# LessLive

Maximize the world, yet minimize living

### 行动的勇气

**读懂了阿德勒，然后真的去活**

## 🤝 我们是谁

LessLive 是一个阿德勒心理学爱好者的共同体。我们只读阿德勒，然后用一套实践工具，把课题分离与共同体感受，活进自己的工作、生活和兴趣爱好里。

我们相信，人缺的往往不是能力，而是行动的勇气；而勇气，来自身边互相鼓励的人。

## 🧭 我们怎么做

| 阿德勒的概念 | LessLive 的工具 | 帮你做到 |
| --- | --- | --- |
| **课题分离** | 品牌故事设计 | 看清自己：我喜欢什么、研究什么、擅长什么 |
| **共同体感受** | 第一人称法则 | 走向他人：从我，到我和你，再到我们 |
| **共同体的维护** | 对外表达策略 | 每一次表达，都展示价值、汇报进度、提供服务 |
| **持续运行** | 增长黑客OKR | 让行动一直跑下去 |

## 📓 [LessLive](https://github.com/lesslive/LessLive)：践行阿德勒的实践模板

以日记为主要的使用方式，在 AI 的协助下记录自己的行动，把实践所得沉淀为可以复用的个人资产。

我们发起的第一个行动计划：**把朋友圈变成生活圈**。

## 🏡 入驻 LessLive，成为生活研究员

把你的仓库部署到 LessLive 组织，向所有成员公开你的行动计划和实践进度。在这里，你会得到鼓励，也去鼓励别人。

- [去看看研究员们的仓库](https://github.com/lesslive)
- [申请加入 LessLive](https://github.com/orgs/lesslive/discussions/1)

## 📜 社群公约

- **只读阿德勒**：我们是爱好者的读书会，不是心理学社区，不诊断、不治疗、不做心理咨询；
- **互相鼓励**：平等地鼓励，不评判、不说教；
- **公开即约定**：入驻即同意仓库公开；写到他人时，不写真实姓名和可识别信息；
- **需要专业帮助时**：我们会陪你找到专业的人。
